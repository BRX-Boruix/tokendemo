# tokendemo

BORUIX 的**端到端验收程序**，验证控制台令牌（console owner）的真值能被用户态如实读到。

[English](README.en.md)

## 测什么

每个终端节点有一个**持有者**记录（谁拥有这个控制台），并可经标准的文件状态查询接口读出。本程序
只经**公开接口**读取该值，不碰任何内核内部结构。

## 钉死的三条不变式

| # | 不变式 |
| --- | --- |
| 1 | **自己的标准流持有者就是自己**——进程建立 fd 0/1/2 时，三个节点即把本进程记为其持有者 |
| 2 | **"是终端"与"有持有者"同时为真**——两条值来自**同一个节点**、经**同一次**查询取回，因此不可能互相矛盾 |
| 3 | **持有者是真 PID，不是常量**——程序把读到的持有者与 `getpid()` 对拍。若内核对持有者虚报（例如恒填 0 或恒填 1），断言即失败 |

## 诚实边界

本程序**只读**持有者，**不测试移交**。谁该持令牌、何时移交属于用户态策略，内核不提供移交动词。

所以它证明的是「持有者真值可被用户态如实读到」，**不**证明「令牌移交可用」。

## 用法

独立运行即可，无需参数。

```
[tokendemo] fd 0/1/2: owner=<pid> is_terminal=1 OK
[tokendemo] PASS
```

## 退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 全部通过 |
| 非零 | 首个失败项编号 |

## 构建

```bash
cargo build --release
```

    └── main.rs   # 三条不变式的检查
